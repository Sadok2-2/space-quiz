# Project rules

- Keep the quiz self-contained in `index.html`; do not add a server or external dependencies.
- Preserve the responsive layout, light/dark color-scheme support, and reduced-motion behavior.
- Use semantic, keyboard-accessible HTML and keep quiz feedback available to assistive technology.
- Keep changes focused and match the existing visual style.
- Verify interactive changes in the integrated browser, including answer feedback, score, and results.
