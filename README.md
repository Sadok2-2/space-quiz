# Orbit Academy — Space Quiz

A self-contained, responsive space trivia quiz. Answer ten questions, learn a
fact after each answer, and review your score and answers at the end. The app
uses only HTML, CSS, and JavaScript in `index.html`; it has no build step or
external dependencies.

## Run locally

Open `index.html` in a modern web browser. No server or package installation is
required.

## Deployment

GitHub Actions publishes the repository to GitHub Pages when changes are pushed
to `main`. The same workflow verifies and packages the site on pull requests;
deployment runs after a successful push to `main`.
